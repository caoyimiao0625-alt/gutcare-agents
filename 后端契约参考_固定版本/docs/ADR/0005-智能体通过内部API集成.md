# ADR-0005：智能体通过版本化内部 API 集成

- 状态：Accepted
- 日期：2026-10-14

## 决策

业务 Worker 在 PostgreSQL 中唯一、原子地 claim 任务，然后调用智能体 `POST /internal/v1/tasks`。智能体通过业务后端任务级输入接口读取冻结快照，并通过 runs/result/fail 回调提交结构化结果。默认不提供业务数据库凭据。

## 理由与后果

避免双重 claim、自由患者查询和智能体写业务表；权限、授权、短时文件 URL、Schema 校验与审计集中在业务后端。重复派发和回调均按 `task_id/callback_id` 幂等，迟到回调不得覆盖终态。
