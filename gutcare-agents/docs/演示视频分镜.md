# 演示视频分镜脚本（8—10 分钟）

> 用法：按镜头顺序录制，每个镜头单独重录，最后拼接。
> 台词只写"要点"，不写逐字稿——照读会生硬，评委更在意现场操作与解释是否对得上。

## 0. 录制前准备（一次性）

| 项 | 要求 |
|---|---|
| 分辨率 | 1920×1080，浏览器缩放 100%，终端字号 16—18px |
| 终端 | 深色主题、清屏、只保留当前命令；`cd E:\仓颉杯\ds\gutcare-agents` |
| 浏览器 | 只开一个标签：`http://127.0.0.1:8100/`；关闭通知与更新弹窗 |
| 启动 | `.\run.ps1 -Mode replay`（或 `-Mode mock`）；**视频里如实说明模式** |
| 预热 | 先跑 `python tools/demo_run.py`，确认 6 步都出结果（这一步不录） |
| 备份 | 若某镜头现场失败，切到 `data/demo/<时间戳>/` 里刚才的 JSON 继续讲 |

## 2. 必须出现的四个"证据镜头"

录完自查，缺一不可：

1. **`needs_confirmation` + 待确认字段**（证明不是"AI 直接下诊断"）；
2. **建议下的依据编号**（证明可追溯）；
3. **`partial` + 原因 + 观察仍在**（证明降级真实发生）；
4. **未确诊患者不给建议**（证明不编造）。

## 3. 配音要点（避免三句话）

- 不说"我们用了先进的 AI 技术"，改说"数字由程序算，模型只解释，所以能核对"；
- 不说"准确率很高"，改说"报告抽取与识菜没有金标准，我们只报可自动量的指标，其余标为未测"；
- 不说"可以替代医生"，改说"只做记录管理与就医提示，不诊断、不改药"。
