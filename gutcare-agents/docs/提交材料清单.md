## 3. 提交前检查（10-22 执行）

- [x] `python -m unittest discover -s tests` 全绿（当前 139）

- [ ] 文档里的数字与 `eval/report.json` 一致，未测项均标注“未测”

## 5. 与另一责任域的接口（联调前对齐）

1. 后端提供：内部鉴权方式、`patient_id`、记录 `id/version/status`、档案快照、受控文件访问方式。
2. 智能体提供：`status` 五态、错误码、`observations`/证据、`uncertainties`、`needs_confirmation`、模型与提示词版本。
3. 双方约定：单 Agent 超时 ≤60s、整体 200s；只对瞬时错误重试；风险提示规则的 `rule_set_version` 必须一致。

详见 `docs/联调接入说明.md`。
