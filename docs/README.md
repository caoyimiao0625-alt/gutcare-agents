# 文档入口

本目录只保留后端联调所需的协议与操作说明，以及后续撰写比赛材料时可核对的设计和证据。**当前实现状态以《智能体详细开发文档》为准；旧版测试数字只作历史取证，不能直接写成当前验收结论。**

## 后端联调

| 文件 | 用途 |
|---|---|
| [后端联调交付说明](后端联调交付说明.md) | 首轮 F08 联调的启动配置、测试任务准备、双方操作与验收口径。建议从这里开始。 |
| [智能体详细开发文档](智能体详细开发文档.md) | 已实现/未实现功能、F08/F09 状态及已验证范围。 |
| [联调接入说明](联调接入说明.md) | 智能体通用 HTTP 接口、异常演练与通用接入。F08 业务接口以固定后端契约为准。 |
| [智能体 OpenAPI](openapi.yaml) | 本仓库提供的通用 HTTP API。 |
| [后端契约参考固定版本](后端契约参考_固定版本/) | 后端 Agent OpenAPI 与 F08、F09、F03/F04、心情授权等 ADR 的固定版本；联调前与实际运行的后端提交核对。 |

单独提供未随仓库交付的 `testdata_v4` 测试包并设置 `GCA_FIXTURE_ROOT` 后，通用请求/响应结构样例可由 `python tools/make_samples.py` 按需生成到 `data/generated_samples/`。它们默认使用 mock，只用于结构核对；该目录不提交到 Git。F08 最小联调不依赖此测试包。`ci.workflow.example.yml` 是待安装的 CI 模板，当前仓库没有根目录 Actions 工作流，不应把它当作已运行的 CI 结果。
