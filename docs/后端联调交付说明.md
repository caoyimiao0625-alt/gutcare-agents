## 先做哪条联调

当前可以先联调 **F08 综合分析**：业务后端领取一条待处理任务，向智能体 `POST /internal/v1/tasks` 派发；智能体根据任务 ID 从后端读取冻结输入，运行分析，向后端提交结果或失败回调；最后使用患者身份查询业务任务结果。建议首轮用 `GCA_MODE=mock`，验证协议和任务状态，不消耗模型额度。`mock` 图片输出不能代表真实识图效果。

F09 仅完成建议载荷的严格格式转换与本地校验，尚未实现独立回调发送和幂等恢复。F03/F04 的 Diet/Stool 识图核心已有，但未实现后端专用图片请求派发、短时受控取图和候选回调。因此本包**不能声称 F09 或 F03/F04 已完成后端联调**。F02 医学文档的业务后端专用解析任务适配也不在本次可交付联调范围。

## 在同伴电脑启动 Agent（PowerShell 示例）

可以直接使用 `docs/F08同伴联调配置.md` 和仓库根目录的 `run-f08-integration.ps1`。脚本在启动时隐藏输入令牌，并显式设置环境变量；下面保留手动方式供排查问题。

需 Python 3.12+。在仓库根目录执行：

```powershell
python -m pip install -r requirements.txt
$env:GCA_MODE = "mock"
$env:GCA_INTERNAL_TOKEN = "<双方约定的 Agent 入站服务令牌>"
$env:GCA_BACKEND_BASE_URL = "http://127.0.0.1:<后端端口>"
$env:GCA_BACKEND_SERVICE_TOKEN = "<后端配置的 Agent 服务令牌>"
python -m gutcare_agents serve --host 127.0.0.1 --port 8100
```

上述占位符需在运行环境替换，不要填写在 Git、聊天记录、日志或交付包中。后端目前使用 `AGENT_SERVICE_TOKEN`（也接受 `AGENT__SERVICE_TOKEN`）作为内部服务鉴权；具体令牌由后端部署方通过安全渠道提供。`GCA_INTERNAL_TOKEN` 是后端 Worker 派发给 Agent 时使用的 Bearer；`GCA_BACKEND_SERVICE_TOKEN` 是 Agent 访问后端内部 API 时使用的 Bearer。两者是否取同一个值以实际部署约定为准。

若 Agent 与后端不在同一台电脑，`GCA_BACKEND_BASE_URL` 必须是 Agent 能访问的地址；Agent 的 `--host` 和后端 Worker 派发目标也必须改为两机可达的地址。`127.0.0.1` 只适用于同机。先确认 Agent `GET /healthz` 返回 `200`，再测试受保护的 `/v1/meta`。本机手动自检命令：

```powershell
python tools/smoke_test.py --base-url http://127.0.0.1:8100 --token $env:GCA_INTERNAL_TOKEN --no-fixtures
```

`smoke_test.py` 的其它通用分析检查可能依赖测试包；F08 的主要判断仍以一条真实后端任务的状态和回调结果为准。

## 后端需准备的一条隔离测试任务

1. 提供可访问且 `/health/ready` 为 200 的后端实例，确认运行提交/迁移版本与包内参考契约兼容。
2. 在**隔离测试库**创建合成患者、有效的基础分析授权、已确认可分析记录和一条 `pending` 的 F08 任务。若测试心情纳入，还需确认四项授权都有效；否则只测试不含心情的任务。
3. 配置内部 Agent 服务令牌、后端 Worker 数据库连接及任务派发目标，并确保只有一个 Worker 消费这条任务。领取接口按时间原子领取，不能指定 task ID；共享队列可能让测试任务被其他 Worker 抢走。
4. 正常有后端 Worker 时由它派发。若开发环境缺少 Worker，可在**停止其他消费者的隔离环境**中，另开终端执行 `python tools/f08_claim_once.py --agent-url http://127.0.0.1:8100`，仅领取一条并派发。不要同时运行该脚本和业务 Worker 抢同一队列。
5. 核对：领取/派发 `202` → 冻结输入读取 → `/result` 或 `/fail` 回调 → 患者身份 `GET /api/v1/analysis-tasks/{task_id}` 达到终态。患者查询必须使用患者 JWT，不能用 Agent 服务令牌代替。保留任务 ID、状态、HTTP 状态码和脱敏日志以便双方定位；令牌和患者原文不进日志。
